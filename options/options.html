2. 自动化程度

本地统计会先遍历整页所有可提取文字，按汉字 / 假名 / 谚文 / 拉丁等文字系统的 占比判断主要语言，再与网页声明的 <html lang> 交叉验证。
多语言站点（页头语言/地区选择器里混了别国文字）容易误判时，选 本地统计 + AI 兜底：只有本地判不准、或统计结果与网页声明冲突时， 才额外发一次请求让模型确认；正常情况下不产生任何额外开销。

3. 分屏界面与版面

上下版面时分隔线变成横向可拖动；无论哪种版面，比例都指「原文栏占多少」， 拖动分隔线、或在弹窗里拉比例条都能调整，双击分隔线回到 50 : 50。

独立小窗基于 Document Picture-in-Picture：译文是实时搬过去的， 关掉小窗会自动搬回分屏位置。浏览器不支持该能力时会降级成普通小窗快照。 译文栏里的链接可以直接点：站内链接在当前标签页打开，站外链接自动新开标签页（按住 Ctrl / 中键也可强制新开）。

4. 全语言识别 API（可选 · 图片取字）

对于正文以图片呈现的页面（海报、截图、漫画、图表），扩展会在配置了本项后调用多模态模型 （同样走 OpenAI 兼容接口）先识别文字、再翻译，并在右栏以卡片形式展示。 未配置时自动降级：右栏对图片区域给出占位提示。

5. 缓存与数据

已翻译的文本会按「服务商 + 模型 + 目标语言」做哈希缓存，命中后不再请求接口，节省额度。

6. 使用说明

  1. 在上面选好服务商并填入 API Key，点右上角「测试连接」确认可用，然后「保存设置」。
  2. 打开任意外语网页，页面顶部会出现提示条，点「翻译」即进入分屏对照。
  3. 译文栏的链接可以直接点：站内链接在当前标签页打开， 站外链接自动新开标签页；按住 Ctrl 或中键点击可强制新开标签页。 页内锚点（#xxx）会让原文栏滚动到对应位置。
  4. 想换版面：弹窗里点「原文在上 / 在左 / 在右 / 在下」四个按钮之一，或在本页第 3 节下拉框选择。
  5. 拖动中间分隔线调整比例（双击回到 50 : 50）；悬停译文可看原文并高亮原文对应段落。
  6. 需要边看边做别的事时，点译文栏状态条上的「独立小窗」，把译文放进可拖动的小窗口。
  7. 想全自动：把「自动化程度」改成「完全自动」。
  8. 浏览器内置页面（edge://、扩展商店等）无法注入脚本，属正常限制。

已知限制：跨域 iframe 内部无法注入（对应位置会显示占位提示）； <canvas> / WebGL 渲染的文字无法提取； 正文为图片的页面需要配置第 4 节的多模态识别接口； 「独立小窗」依赖 Document Picture-in-Picture（Edge / Chrome 116+）， 不支持的浏览器会降级为普通小窗快照。
