## 二、Microsoft Edge 加载项商店

### 名称（上限 45 字符）

```
分屏翻译 · Split Translate
```

### 简短说明 / Summary（上限 132 字符，搜索结果里显示的就是这句）

```
自动检测非简体中文网页，一键左右分屏对照翻译：左边原文、右边中文，保留原页面排版，支持 DeepSeek 等任意 OpenAI 兼容接口。
```

### 详细说明 / Description

```
【它解决什么问题】
读外文新闻、文档、论文时，浏览器自带翻译会把原文整页替换掉，想核对一句原话就得来回切换，
专有名词与语气也常被抹平。分屏翻译把页面从中间分开：一边原文、一边简体中文，逐段对照，
看不懂的地方眼睛往旁边一移就行。

【主要特性】
• 自动语言检测
  识别英语、法语、德语、西班牙语、葡萄牙语、意大利语、荷兰语、越南语、印尼语、土耳其语、
  波兰语、俄语、阿拉伯语、希腊语、泰语、日语、韩语、繁体中文等；简体中文页面自动跳过。

• 不破坏原页面
  原文栏用的是页面原始 DOM，原站 CSS 完全生效，布局、字体、表格、图片位置都不变；
  译文栏是结构完全一致的镜像，只把文本换成简体中文。

• 只翻译该翻译的
  自动跳过代码块、命令行、URL、邮箱、纯数字、已标记 translate="no" 的区域，不碰页面脚本。

• 批量请求 + 本地缓存
  多段文本合并成一次请求，相同内容只请求一次；已翻译内容按「服务商 + 模型 + 目标语言」
  缓存在本机，再次访问同一页面几乎零请求，省额度也更快。

• 译文栏可以直接操作
  译文里的链接同样可点：站内链接在当前标签页打开，站外链接自动新开标签页。
  鼠标悬停译文会显示原文气泡，并高亮左侧对应的原文段落，方便逐句核对。

• 版面与比例随你
  原文可以放在左、右、上、下任意一侧；中间分隔线可拖动，双击回到五五开；
  译文栏还能放进一个独立的可拖动小窗，边看边做别的事。

• 四种自动化程度
  智能提示（顶部提示条点一下才翻译）、完全自动、仅手动、关闭扩展。

• 可选图片取字
  正文以图片呈现的页面（海报、截图、图表），配置一个多模态识别接口后会自动先取字再翻译。

【支持的服务商】
任何 OpenAI 兼容接口都能用，只需填 Base URL、API Key、模型名：
  DeepSeek      https://api.deepseek.com/v1          deepseek-chat
  MiniMax       https://api.minimax.cn/v1            MiniMax-M3
  亦可自定义     OpenAI、硅基流动、月之暗面、阿里云百炼、本地 Ollama 等

可选「思考强度」参数（reasoning_effort），接口不支持时会自动去掉该参数重试，不会因此翻译失败。

【隐私】
API Key 与翻译缓存只保存在你自己的浏览器本地存储中，扩展不向任何第三方服务器发送数据，
除你自己配置的翻译接口外不产生任何网络请求。扩展不含任何统计、追踪或广告代码。

【已知限制】
• 浏览器内置页面（edge://、扩展商店等）无法注入脚本，属浏览器限制
• 跨域 iframe 内部无法注入，对应位置会显示占位提示
• 用 canvas / WebGL 绘制的文字无法提取
• 正文为图片的页面需要自行配置多模态识别接口
• 独立小窗依赖 Document Picture-in-Picture（Edge / Chrome 116+），不支持的浏览器降级为普通小窗

【开源】
源代码与完整测试见 GitHub 仓库，欢迎提交 issue。
```

### 权限说明（提交时通常需要逐条解释，可直接用）

| 权限 | 用途说明 |
|---|---|
| `storage` | 保存用户填写的接口配置、界面偏好与本地翻译缓存 |
| `scripting` | 在用户主动触发时向页面注入分屏翻译脚本 |
| `activeTab` | 仅作用于用户当前操作的标签页，用于读取页面内容并显示译文 |
| `tabs` | 在译文栏点击链接时，按站内/站外策略决定当前标签页跳转还是新开标签页 |
| `contextMenus` | 提供「分屏翻译此页面」「翻译选中文本」右键菜单 |
| `notifications` | 划词翻译结果以系统通知形式展示，避免改动页面结构 |
| `<all_urls>` | 翻译功能需要作用于用户访问的任意网站；扩展不会后台自动上传任何页面内容 |

### 单一用途说明（Single purpose，Edge/Chrome 都要填）

```
把用户正在浏览的非简体中文网页分成原文与简体中文译文两栏并排显示，方便对照阅读。
```
